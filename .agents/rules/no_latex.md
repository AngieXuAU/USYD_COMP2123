# Rule: Formatting Preference - Plain Markdown over LaTeX

- Do NOT use LaTeX math syntax (e.g. `$...$`, `$$...$$`, `\(...\)`, `\[...\]`).
- Use plain Markdown formatting (inline code blocks, bold, standard text) for Big-O notation, equations, variables, and math expression (e.g. `O(n + m)`, `Theta(n^2)`, `n(n - 1) / 2`, `deg(v)`).
